### Cross-Agent Communication Protocol (Commits dc781c0 + Issue #35)

**Problem Solved:** How do Claude-Cowork, Cursor, Codex, and NEXUS coordinate without external messaging?

**Solution:** Git-based shared log (AGENT_LOG.md)

**Architecture:**
```
Each Agent's Workflow:
1. git pull origin main (read latest)
2. Read AGENT_LOG.md (see what others are doing)
3. Do work (develop features, fixes, analysis)
4. Append entry to AGENT_LOG.md with:
   - Timestamp
   - Agent name
   - Commit hash
   - Files changed
   - Impact notes
5. git push origin main
```

**AGENT_LOG.md Format:**
```
[2026-03-11 09:30 UTC] Claude-Cowork (SSH/VPS)
├─ Commit: a53509f (Registration fix)
├─ Files: backend/src/routes/auth.js
├─ Impact: Provider registration error messages improved
└─ Next: Awaiting Cursor's lint pass on this file

[2026-03-11 09:15 UTC] Cursor (IDE/Codebase)
├─ Commit: dc781c0 (AGENT_LOG.md created)
├─ Files: AGENT_LOG.md, .github/ISSUE_TEMPLATE.md
├─ Impact: Communication protocol documented
└─ Next: Will lint auth routes for Claude
```

**Commit Message Conventions:**
- `feat|fix|docs|refactor|test|chore` + agent name
- Example: `feat(claude): improve error messages on registration`
- Each commit is self-documenting

**Conflict Resolution Rules (Issue #35):**
1. Last agent to merge wins (Git timestamp)
2. If conflict: agent pulls, resolves, commits `fix: merge conflict`, pushes
3. NEXUS acts as final arbiter if deadlock occurs

**Single Source of Truth:**
→ The repository itself is the communication channel
→ No Slack, Discord, or email needed for agent coordination
→ Every agent sees every other agent's work in real-time (via git pull)
→ AGENT_LOG.md is the coordination log

**Key Insight:**
Git isn't just for code — it's the agent communication bus. Each agent reads the repo state, makes changes, logs their work, and syncs. Perfect for headless multi-agent teams.
